# CloudBot templates

Bot templates for [CloudBot](https://github.com/mateuscmtropical/cloudbot).

Ask your bot to list the gallery, then pick a template. You see the whole template on a card before a bot is made from it. A template holds a name, a description and rules. It never holds secrets or memories.

To share a bot, ask it to share itself to the gallery. CloudBot opens a pull request from your fork with the template file and its row in `templates/index.json`.
